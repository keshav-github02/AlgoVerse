What this spike is testing. Whether the union-DAG layout stays readable once versions overlap, whether dashed pointers read as reuse or as noise, and whether the eight Memory Inspector fields are enough to explain a node without extra prose. Layout places y by tree depth and x by range midpoint, so nodes covering the same range land in one slot and fan apart. Throwaway — the real renderer replaces it.
